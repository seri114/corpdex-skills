# corpdex 貢献タスク

corpdex の貢献はクロール(企業サイトの調査と提出)とレビュー(他者の提出の出典突合)の総称で、どちらも同じ貢献ポイントに入る。あなたが行うのは **①キューの確認 ②振り分け ③実行 ④報告** の4つだけ。レビューかクロールかは自分で選ばず、**キュー状況で決まる**。

**絶対守則**

1. **レビューを優先する**: 投稿はレビュー2件で着地するためレビューが律速。pending があるときにクロールはしない。**1回の実行は1件だけ**で、実行したら報告して終了する
2. **ページの取得は `corpdex fetch` のみ**。レビューでは出典テキストがパケットに同梱されるため再取得しない(クロールの取得マナーは crawl スキルの守則に従う)
3. 判定・抽出はユーザーの手元の LLM が行う。corpdex 側に LLM はない

## 0. 前提

- `corpdex` CLI が入っている(未導入なら `${CORPDEX_API_URL}` の配布ページ `/dist` の手順で導入)
- 環境変数 `CORPDEX_TOKEN`(tasks・review の両スコープを推奨)と `CORPDEX_API_URL` が設定済み。無ければユーザーに設定を促して終了する
- 空の作業ディレクトリで実行する(fetch計数を `.corpdex/` に、突合パケットを `review-packets/` に置くため)

## 1. キューの確認と振り分け

```
corpdex review list
```

- **pending が1件以上ある** → §2 レビューを1件実行する
- **「pending の投稿はありません」** → §3 クロールを1件実行する
- **403**(review スコープの無いトークン)→ §3 クロールを1件実行する
- **401・接続エラー** → ユーザーに案内して終了する(トークン・API URL の確認)

## 2. レビューを1件実行する

1. `corpdex review list` の**先頭の行**(古い順。⚠ は72時間超の滞留)から投稿ID(`s_` で始まる)を取る
2. `corpdex review prepare <投稿ID>` で突合パケットを `review-packets/<投稿ID>.md` に生成する(状態を変えない操作)
3. パケットを読んで判定する。**判定基準はパケットの冒頭に書かれているので、それに従って確認する**(出典テキストは同梱済み — URL を自分で再取得しない)
4. 判定を記録する:
   - 問題ないとき: `corpdex review approve <投稿ID>`
   - 問題があるとき: `corpdex review reject <投稿ID> --comment "理由"`(comment は投稿者に届く却下理由 — 何が悪く何をすべきかを書く)
5. **403 self_review_forbidden**(自分の投稿)なら判定を記録せず、リストの次のIDで手順2からやり直す。pending を使い切ったら §3 へ進む

判定に迷うとき・大片の変更のときは、判定根拠を要約してユーザーに確認してから記録する。

**運営者(admin スコープ)の差分**: `corpdex admin review approve` は1件で確定する。自分で作った直後の投稿は prepare を飛ばして approve に直行してよい(パケットは他者の投稿や自信のない場合の支援)。

## 3. クロールを1件実行する

crawl スキルの手順に従ってクロールタスクを1件実行する(導入済み — `corpdex skill install` が `~/.claude/skills/crawl/SKILL.md` と `~/.codex/skills/crawl/SKILL.md` に配置する)。

- claim が `task: null`(配布できるタスクなし)を返したら、その旨を報告して終了する
- claim が 403(tasks スコープの無いトークン)を返したら、トークンのスコープを案内して終了する

## 4. 報告と継続

実行した内容(レビュー1件 or クロール1件)と結果をユーザーに報告して終了する。**継続を指示されたら §1 からやり直す**(振り分けはその時点のキュー状況で再判定する)。キューも在庫も空になったら「レビュー待ちもタスク在庫もありません」と報告して終了する。

## 環境非依存の確認

操作はすべて `corpdex` CLI・環境のWebSearch(クロール時のみ)・ファイル読み書きのみ。Claude Code / OpenAI Codex の両方で同じ手順で動く(動作保証はこの2環境)。
